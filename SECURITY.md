# Security policy

Report vulnerabilities through GitHub's private
[security advisory form](https://github.com/pawnkit/pawn-analysis/security/advisories/new).
Please do not open a public issue before a fix or mitigation is available.

Untrusted Pawn source, includes, API metadata, and cached snapshots are in
scope. Panics, unbounded expansion, path escapes, or resource exhaustion in a
long-running editor or CI process should be reported.
